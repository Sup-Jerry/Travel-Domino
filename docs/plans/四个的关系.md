## 用户旅程覆盖

```
[看到灵感] → 碎片导入
    ↓
[生成行程] → 现有规划核心
    ↓
[旅途中] → 在途动态重排
    ↓
[旅行结束] → 归档闭环
    ↓
[下次复用] → 模板 → 碎片导入入口
```

多人协作横跨全程，是治理层。

## 共享技术基础

| 能力 | 复用方 |
|------|--------|
| `undoToken` 回滚 | 动态重排、多人协作 |

## 各计划 DoD 快查

### P0 在途动态重排
- [ ] PUSH_DOWN / DROP / REORDER 三种方案可生成并执行
- [ ] 锁定事件不被修改
- [ ] 执行失败可回滚
- [ ] 单测覆盖触发、生成、执行三层

### P1 碎片导入
- [ ] 文字 / 链接 / 截图三种源可解析
- [ ] AI 失败有正则兜底
- [ ] 写入可撤销
- [ ] 单测覆盖解析与写入

### P1 归档闭环
- [ ] 事件可标记到访 / 跳过
- [ ] 花费、备注、照片可挂载
- [ ] 复盘摘要可生成（规则兜底）
- [ ] 历史行程可转模板复用

### P2 多人协作
- [ ] Owner / Collaborator 权限隔离
- [ ] 提案工作流全链路可走通
- [ ] 偏好权重冲突提示可生成
- [ ] 执行阶段已到访事件不可被提案修改
